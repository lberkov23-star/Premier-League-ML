# Premier-League-ML
Basic Machine Learning model for premier league prediction

## Overview

This project was a test model for a premier league prediction tool.

## Methods

The project uses machine learning techniques including:

- Pandas
- scikit-learn
- Logistic Regression
- Random Forest Classifier

## Expectations

This model was built from rudimentary coding knowledge and should do better than ~50% with predictions.

## Results

The results were slightly better than expected. The project especially did well with the Random Forest Classifier, although the overall performance is still by no means trustworthy.
